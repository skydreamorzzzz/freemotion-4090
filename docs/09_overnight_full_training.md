# 12 小时全量单人 baseline 训练

用户授权由 8 小时改为 12 小时。目标是增加数据覆盖和有效训练量，不能保证一晚达到论文的 2500 epoch。此前原始随机初始化、200/2000 步冻结对照、解冻对照的权重均保留。本轮回到原版冻结模型，从原随机 checkpoint 开始；没有 RAG、额外距离引导或几何修正。

## 数据与优化

全量 5629 个有效 train ID，经原始镜像增强组成每轮 11258 条。保留原始随机文本、人物选择与长序列随机裁剪，恢复 300 帧上限；短序列有 padding，有效帧 mask 沿用原实现。按需读取、单进程，不把完整动作集载入内存。原始 split 不变。

microbatch=1、梯度累积16、FP32、AdamW lr=1e-4、weight_decay=2e-5。每条 loss 除以本次实际累计条数，完成累积后才裁剪梯度至0.5并更新优化器。每轮最后10条以实际10条平均，不丢数据。每轮704次优化器更新；正常有效 batch=16，并非论文单卡80或多卡全局 batch。

学习率只在完成11258条的一轮后调用原 CosineWarmupScheduler：warmup=10 epoch、max_iters=2500。区分 microsteps、optimizer updates 和数据 epoch，不能将每条前向算成一次优化器更新。梯度累积降低了梯度估计噪声，但不保证逐位等价于真实大 batch，尤其原损失对不同长度样本的归约方式需保留说明。

## 运行与恢复

入口 `scripts/train_overnight.py`，输出 `artifacts/overnight_full_single/`。已实际完成3次更新的试跑，保存后恢复到第5次更新（80条样本），没有从头重复。参数、优化器、scheduler、随机状态、当前epoch顺序和游标均保存；恢复时严格检查数据顺序签名和训练配置。

每15分钟及每轮结束原子替换 `latest.ckpt`，仅保留最新完整断点，避免磁盘随轮数增长。每轮在固定4个val样例上计算去噪MSE，验证前后恢复随机状态和训练模式，改善时另存 `best_validation.ckpt`。该小验证仅用于诊断/保留候选，不是完整生成质量指标。

预算按累计训练运行时间计算，启动扫描和中断期间不计入；约12小时后完成当前累积批、验证并保存退出，不是到点强杀。若进程异常，保留上一次完整断点，不把部分梯度或失败权重写成成功结果。`status.json` 和 `progress.jsonl` 提供状态和计数。

后台进程使用隐藏窗口。运行期间通过 Windows 临时执行状态请求防止空闲睡眠；退出后自动释放，不永久修改电源设置。用户手动休眠、关机或合盖仍可能中断。应接电并保持机器可持续运行。

停止：在输出目录创建名为 `STOP` 的文件，完成当前累积批后保存退出。继续前移走该文件，运行：

```powershell
& E:/套磁/代码重构/.venv/Scripts/python.exe E:/套磁/代码重构/scripts/train_overnight.py --resume --hours 12
```

## 后续正式评估准备

评估脚本新增 `--samples 0` 使用全部有效 split ID，`--seed` 可做独立重复；仍按96个候选分组计算检索，与官方 drop_last=True 对齐。1099个test会产生1056个纳入指标的样本、43个尾部未纳入；报告显式记录，不悄悄把候选数扩大成1099。每个新seed应使用独立输出目录，多次结果需汇总均值与区间，不能只挑最好的一次。

此次长跑不自动启动耗时不定的正式test评估，也不声称已完成全量多次评价。先检查训练和val趋势，再执行完整评价。新增全量评估模式尚未实跑验证，既有96样本结果保留。
