# 与 FreeMotion 论文指标对照：96 条测试样本试评估

## 先明确比较对象

当前最新 checkpoint 是单人生成模块训练 2000 步的结果，不能直接与论文双人交互表 1 比较。对应的是 [FreeMotion arXiv v1 表 2](https://arxiv.org/html/2405.15763v1#S5.T2)：根据两个人各自的描述，分别独立生成动作，再拼接成双人输入交给 InterCLIP 评估，使用整体场景描述计算文本匹配。两个人独立采样，不输入对方动作，也不将场景描述加进生成条件。

论文表 2 FreeMotion 的均值：R-Precision top-1/2/3 为 0.264 / 0.394 / 0.473，FID 为 12.975，MM Distance 为 3.885。表 1 的双人交互 FID 6.740 属于另一任务设置，不用于计算本轮差值。

此前的 normalized denoising MSE、每帧关节位移和训练 loss 都是诊断量，不是上述论文指标。MSE 降低不能换算成“距 FreeMotion 还差多少”。

## 本次评估协议

- 从原始 test 划分中用固定 seed=20261004 选取 96 个 ID，不与本轮 train/val 子集重叠。使用已记录的缺失资产和上游短动作过滤规则；实际 ID、文本、人物顺序与长度保存在 manifest。
- 保留官方测试数据处理和 300 帧输入上限，不将评估缩短到训练时的 120 帧。每个人独立用 DDIM50 采样。
- 使用已下载的官方 InterCLIP 权重，严格载入。模型生成完释放后再加载评估器，以节省显存。
- embedding 逐条计算；汇总后形成完整 96×96 距离矩阵计算检索。逐条编码不等于将检索候选数改成 1。
- FID 调用上游特征缩放、均值协方差和 Frechet 距离函数；MM Distance 为配对文本/动作 embedding 的平均欧氏距离；R-Precision 为正确配对在 top-k 的命中率。
- 同一批真实测试动作也计算文本匹配指标，用于检查评估口径。真实 FID 使用自身作为参考，理论上为 0；不能拿它与论文的独立抽样 Real FID 直接比较。

首次按需加载测试集时，官方推理数据类保留了短动作条目，访问时 load_motion 返回 None。试评估入口现根据之前全量审计的短动作名单在抽样前排除，未对失败样本临时挑选替代，未改变官方 split。

## 边界

这是 96 个样本、一次采样的试评估；论文表 2 沿用表 1 的多次评估协议。512 维特征在 96 个样本下协方差秩不足，FID 存在显著有限样本偏差。数值差可以作为粗略参照，不能包装为正式复现差距或置信区间。

本次未测 Diversity / Multimodality。训练仅用 32 个片段且上限 120 帧，测试恢复官方长度，本身也包含长度外推问题。当前不根据这批 test 分数反复挑选参数；后续调参应使用 val，将正式 test 留作最终评价。

执行入口：`scripts/evaluate_single_pilot.py`。产物目录：`artifacts/single_2000_metrics96/`，包括样本清单、原始生成/参考动作、embedding 和指标报告，便于追溯和重新计算。

## 实测结果（2026-10-03）

| 指标 | 论文单人表 2 | 本机 2000 步，96 条试评估 | 数值差（仅粗略参照） |
|---|---:|---:|---:|
| FID ↓ | 12.975 | 161.678 | +148.703 |
| R-Precision top-1 ↑ | 26.40% | 4.17%（4/96） | −22.23 个百分点 |
| R-Precision top-2 ↑ | 39.40% | 7.29%（7/96） | −32.11 个百分点 |
| R-Precision top-3 ↑ | 47.30% | 11.46%（11/96） | −35.84 个百分点 |
| MM Distance ↓ | 3.885 | 4.179 | +0.294 |

论文数值来源为上面的 arXiv v1 表 2，当前值来自 `report.json`；这里并列的是论文全量重复评估与本机单次小样本结果，差值不等于严格同协议的正式差距。FID 的维数 512 大于样本数 96，不能省略该限制。Diversity / Multimodality 未测，不能填 0 或用运动幅度代替。

同批真实动作 top-1/2/3 为 46.875% / 67.708% / 77.083%，MM Distance 为 3.7912。它说明这批文本与真实动作有明显可检索关系；当前生成的检索命中率远低于真实动作。自比较 Real FID 为 −0.0000201，属于矩阵平方根的数值舍入误差，保留原值，理论值为 0；它不是负的真实距离。

96 个测试 ID 均唯一，动作有效长度为 16–299 帧，其中 25 条超过训练时的 120 帧上限。训练与验证诊断改善，尚未转化为接近论文水平的自由生成质量。可能因素包括极小训练集、短训练、长度外推及随机冻结文本适配层，当前评估无法单独归因。后续应在 val 上逐项对照，而不是依据本批 test 结果反复调整参数。
